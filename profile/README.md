# Ecom Swift LLC

We are a Shopify Partner and development company. We build fast storefronts, custom apps and the small tools that keep a store tidy behind the scenes.

## What we do

Shopify theme design and development, custom apps built on the Admin API and Shopify Functions, store and data migrations, performance and accessibility audits, and ongoing maintenance for growing merchants.

## Open source

The repositories here are the tools we reach for on client work, released for other Shopify developers to use.

- [shopify-liquid-linter](https://github.com/Ecom-Swift-LLC/shopify-liquid-linter) - flags deprecated tags, filters and accessibility problems in Liquid templates.
- [shopify-theme-performance-auditor](https://github.com/Ecom-Swift-LLC/shopify-theme-performance-auditor) - scans a theme for performance issues and outputs a fix report.
- [shopify-csv-product-fixer](https://github.com/Ecom-Swift-LLC/shopify-csv-product-fixer) - validates and repairs product CSV exports before import.
- [shopify-functions-examples](https://github.com/Ecom-Swift-LLC/shopify-functions-examples) - annotated Shopify Functions examples in Rust and JavaScript.
- [shopify-metafields-manager](https://github.com/Ecom-Swift-LLC/shopify-metafields-manager) - bulk create, edit and export metafield definitions and values.
- [shopify-webhook-toolkit](https://github.com/Ecom-Swift-LLC/shopify-webhook-toolkit) - verify, log and replay webhooks while you develop.
- [shopify-app-starter-remix](https://github.com/Ecom-Swift-LLC/shopify-app-starter-remix) - starter template for embedded apps built with Remix and Polaris.
- [shopify-order-export-cli](https://github.com/Ecom-Swift-LLC/shopify-order-export-cli) - export orders and line items to CSV from the command line.
- [shopify-theme-deploy-action](https://github.com/Ecom-Swift-LLC/shopify-theme-deploy-action) - lint and deploy themes straight from GitHub Actions.
